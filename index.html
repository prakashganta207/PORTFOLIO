03 · Projects

01 · Flagship Production-ready

Local Admission Information Agent

Glass-box vs. black-box AI agent research · 3-person team

A privacy-safe, fully local RAG system built as a research comparison between a monitored ("glass box") AI agent and an unmonitored ("black box") one. Everything runs locally for data privacy: Qwen via Ollama/vLLM as the LLM, FAISS/Chroma for retrieval, OpenTelemetry + OpenInference for full instrumentation, a custom telemetry pipeline into MySQL, and a Streamlit/Grafana explainability dashboard.

The core question: how much faster can you detect and recover from agent failures — hallucination, context degradation, hard crashes — when the agent is fully observable?

  • MTTRMean time to recovery
  • DetectionReactive vs. proactive
  • ~10–15%Telemetry latency overhead
  • CoverageFailure classes caught

Code Guard

ML-based detection & self-correction of security vulnerabilities in LLM-generated code
