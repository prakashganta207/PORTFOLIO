Local Admission Information Agent

Glass-box vs. black-box AI agent research

A privacy-safe RAG system that runs entirely locally (Qwen via Ollama/vLLM, FAISS/Chroma for retrieval) and is fully instrumented with OpenTelemetry + OpenInference. The core research question: how much faster do you detect and recover from failures — hallucination, context degradation, hard crashes — when an agent is observable versus when it's a black box? Includes a custom telemetry pipeline into MySQL and a Streamlit/Grafana explainability dashboard.
